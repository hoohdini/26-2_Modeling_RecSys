# 실험 결과 한눈에 — 2026-09-20 기준

9/15부터 9/20까지 끝난 실험 전부를 한 장으로 정리한다. 수치는 전부 자동 판정표(`results/reports/`)와 결과 JSON(`results/`)에서 그대로 옮겼고, 여기서 새로 만든 숫자는 없다. 발표 자료는 이 문서의 표를 그대로 쓰면 된다.

## 0. 이 문서를 읽는 데 필요한 용어 세 개

| 용어 | 뜻 |
|---|---|
| 노이즈 바닥 | 같은 설정에서 시드(난수)만 바꿔 여러 번 돌렸을 때 결과가 흔들리는 최대 폭. 두 조건의 차이가 이 폭보다 작으면 우연으로 보고 주장하지 않는다 |
| 짝지은 t | 같은 시드끼리 두 조건의 차이를 구해 그 평균이 0과 다른지 보는 검정. 시드 6개면 2.015보다 크면 유의하다고 본다 |
| G1 대조 | 그래프의 간선만 무작위로 다시 이어(차수는 그대로) 같은 실험을 돌리는 것. 이때 이득이 사라져야 이득이 그래프의 의미에서 왔다고 말할 수 있다 |

시드 1개짜리 수치는 어디에도 인용하지 않는다.

## 1. 한 줄 결론

그래프로 만든 아이템 주소(G-SID)는 텍스트 주소보다 두 도메인(Amazon Beauty, 구인구직 v4), 세 트랙(LOO, Temporal W4, W5), 세 학습 예산(15k, 30k, 45k)에서 일관되게 낫고, 그 이득은 무작위 그래프에서 사라진다. 구인구직 v3의 주지표와 다양성 개선은 주장하지 않는다.

학습 레시피는 전부 같다. TIGER, 30,000스텝, 코드북 256, 4단계. 5시드는 42·7·13·3·21, 3시드는 42·7·13이다.

접두사 제약 디코딩(생성 도중 존재하지 않는 주소를 쳐내는 옵션)을 켜면 무효 주소 비율이 1.3~1.7%에서 0이 되지만 정확도는 0.1% 줄고 콜드 recall만 3~4% 오른다. 학습에 한 번도 안 나온 아이템(zero-shot 138건)은 켜도 0이다. 그래프 우위는 제약을 켜도 그대로다.

실패한 대조 2건(코드북 재균형 CRAB, 확산 다이얼)은 `SHARE_GSID_결과요약.md` 8절에 있다.

## 3. 구인구직 (자체 생성 데이터셋)

사람이 아이템이다. user는 채용담당자, item은 후보자 프로필, 콜드 아이템은 신규 가입자다. 학습은 30,000스텝, 조기종료 없음.

### 3-1. v3 (6시드: 42·7·13·3·21·99)

| 지표 | 텍스트 | G-SID | 차이 | 짝지은 t (기준 2.015) | 사전등록 바닥 방식 |
|---|---|---|---|---|---|
| recall@10 | 0.0705 | 0.0753 | +0.0049 (+6.9%) | 2.33 유의 | 시드 99 부호 반전 |
| NDCG@10 (주지표) | 0.0347 | 0.0363 | +0.0017 (+4.8%) | 1.34 미확인 | 부호 반전 |
| recall@50 | 0.2230 | 0.2424 | +0.0193 (+8.7%) | 4.90 유의 | 최소 효과가 바닥 아래 |
| NDCG@50 | 0.0673 | 0.0721 | +0.0048 (+7.2%) | 3.08 유의 | 부호 반전 |
| G1 무작위 그래프 (3시드) | 전 지표에서 이득이 음수로 반전 | | | | 통과 |

시드 99 하나에서 그래프가 텍스트보다 낮게 나왔다. 그 셀은 정상 완주했고 다시 돌리지 않았다. 발표에서는 recall@10·recall@50·NDCG@50 개선까지만 말하고 주지표는 미확인이라고 쓴다. 9/1 문서의 3시드 수치(recall@50 +11.1%, few-shot 1.68배)는 6시드 값(+8.7%, 1.15배)으로 바꿔 쓴다.

### 3-2. v4 (캐글 실측 분포로 상호작용을 다시 만든 데이터, 6시드)

프로필·텍스트·그래프는 v3와 같고 상호작용만 캐글 CareerBuilder 2012의 분포(아이템 Gini 0.584, 상위 50% 점유 86.4%)에 맞춰 다시 생성했다. v3와 v4는 데이터가 달라 수치를 비교하지 않고 재현 여부만 본다.

| 지표 | 텍스트 | G-SID | 차이 | 짝지은 t (기준 2.015) | 6시드 부호 |

| recall@10 | 0.0594 | 0.0658 | +0.0065 (+10.9%) | 14.8 유의 | 6/6 |
| NDCG@10 (주지표) | 0.0292 | 0.0322 | +0.0031 (+10.5%) | 11.4 유의 | 6/6 |
| recall@50 | 0.1954 | 0.2134 | +0.0181 (+9.2%) | 7.26 유의 | 6/6 |

사전등록 바닥 방식은 시드가 늘수록 바닥이 커지는 성질이 있어 3시드에서는 4지표 통과, 6시드에서는 recall@50만 통과한다. 효과 크기는 두 경우가 같다(NDCG@10 +0.0030 대 +0.0031). 두 방식을 나란히 싣고 순서를 밝힌다. 노출 구간별로는 low(4~5회 등장) 구간에서 1.26배로 이득이 가장 크고 head로 갈수록 1.08배로 줄어드는 구조가 v3와 같다. zero-shot은 0이다.

## 5. 발표에서 써도 되는 문장과 안 되는 문장

| 써도 되는 것 | 안 되는 것 |
|---|---|
| Beauty에서 그래프 주소가 텍스트 주소를 이긴다. 5시드, 세 트랙, 세 예산 | 튜닝식이 고전 블렌딩보다 낫다 |
| 구인구직 v4에서 재현된다. 6시드 4지표 유의, G1 통과 | 구인구직 v3 주지표가 개선됐다 |
| 이득은 콜드·희귀 아이템에서 크다 | 다양성이 좋아졌다 |
| 이득은 그래프의 의미에서 온다(G1) | v3 대비 v4가 몇 % 좋아졌다 |
| zero-shot은 못 뚫었고 원인은 주소 할당 커버리지다 | 접두사 제약이 zero-shot을 연다 |
