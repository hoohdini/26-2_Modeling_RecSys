# 3. 🎉 그런데 실제로는 안 씁니다

코드에서 import 여부를 전수 확인했습니다.

| 패키지 | 코드에서 import | 판정 |
|---|---|---|
| torchrec | **0곳** | 불필요 |
| fbgemm | **0곳** | 불필요 |
| deepspeed | **0곳** | 불필요 |
| bitsandbytes | **0곳** | 불필요 |
| flash_attn | **0곳** | 불필요 |
| tensorflow | 2곳 | **필요** (TFRecord 읽기) |

**`requirements.txt`는 `pip-compile`이 전이 의존성까지 전부 고정한 결과일 뿐입니다.**

## CUDA 하드코딩도 2줄뿐입니다

```python
# src/utils/restart_job_utils.py:215
if torch.cuda.is_available():      # ← 조건부. 없으면 그냥 건너뜀
    torch.cuda.empty_cache()
```

## CPU/GPU 설정이 이미 분리돼 있습니다

```
configs/trainer/default.yaml   →  accelerator: cpu
configs/trainer/ddp.yaml       →  accelerator: gpu
```

PyTorch Lightning은 `accelerator: mps`(Apple GPU)를 지원합니다.

# 4. 설치 절차

## 4-1. 가상환경 (Python 3.11 권장)

```bash
conda create -n grid python=3.11 -y
conda activate grid
```

> ⚠️ 이 맥의 conda에 권한 문제가 있었습니다 (`__conda_exe: permission denied`).
> 안 되면 venv를 쓰세요.
> ```bash
> python3.11 -m venv ~/venvs/grid
> source ~/venvs/grid/bin/activate
> ```

## 4-2. 최소 설치 (954개 전부 X)

```bash
# PyTorch — Mac ARM용이 자동 선택됩니다 (CUDA 아님)
pip install torch torchvision

# 학습 프레임워크
pip install lightning pytorch-lightning

# 설정 관리
pip install hydra-core omegaconf

# 모델·토크나이저
pip install transformers sentencepiece

# 데이터
pip install pandas pyarrow numpy
pip install tensorflow-macos        # TFRecord 읽기용

# 기타
pip install rich tqdm scikit-learn
```

**실행하면서 `ModuleNotFoundError`가 뜨는 것만 추가로 설치하세요.**

## 4-3. MPS 동작 확인

```bash
python -c "
import torch
print('torch:', torch.__version__)
print('MPS 사용 가능:', torch.backends.mps.is_available())
print('MPS 빌드됨:', torch.backends.mps.is_built())
"
```

`True`가 나오면 Apple GPU를 쓸 수 있습니다.

## 4-4. 실행 시 가속기 지정

```bash
# CPU
python -m src.train experiment=... trainer=default

# Apple GPU (MPS)
python -m src.train experiment=... trainer.accelerator=mps
```

# 8. Ghost는 이 맥에서 어려울 것입니다

```
stage_1.sh:  torchrun --nproc_per_node=2  +  DeepSpeed
백본:        Qwen2.5-3B (30억 파라미터)

→ NVIDIA GPU 2장 전제
→ DeepSpeed는 MPS 지원이 사실상 없음
→ 24GB 통합 메모리로 3B 파인튜닝은 매우 빠듯
```

**Ghost는 코드·데이터 참고용으로만 쓰고, 실행은 GRID로 하시는 걸 권합니다.**
랩에 NVIDIA GPU가 있으면 그때 재검토하면 됩니다.
