# ⬜ 다음 할 일

## 🟡 확인 필요

```
⬜ 랩 GPU 사양 확인          ← 이게 실험 규모를 결정합니다
      ① 어떤 GPU인가         (A100 / A6000 / RTX 4090 ...)
      ② 메모리 몇 GB인가      ← 8GB 이상이면 우리는 충분
      ③ 몇 장 쓸 수 있나
      ④ 한 번에 몇 시간까지   ← 가장 중요
      ⑤ 큐 대기가 있나
      ⑥ 몇 명이 나눠 쓰나
```

> TIGER는 1,300만 파라미터로 아주 작습니다. **메모리는 1~2GB면 됩니다.**
> 병목은 메모리가 아니라 **시간**입니다 (Beauty 200k steps).

## 🟢 실행

```
⬜ Step 1  가상환경 + 최소 설치 (Python 3.11)          30분~1시간
⬜ Step 2  MPS 동작 확인                                5분
⬜ Step 3  임베딩 생성 (Flan-T5-XL 3GB 다운로드 포함)
⬜ Step 4  코드북 학습 → SID 생성
⬜ Step 5  TIGER 학습 (steps 200k → 2k 로 줄여서 먼저)
⬜ Step 6  ★ 재현 검증
              Recall@10  0.0639
              NDCG@10    0.0347
              ±5% 이내

⬜ Step 7  구간별 평가 코드 작성 (2~3일)
⬜ Step 8  Phase 1 실험 (L ∈ {2,3,4,5} × 시드 3 = 12회)
```

**Step 6이 관문입니다. 여기만 통과하면 나머지는 순조롭습니다.**
