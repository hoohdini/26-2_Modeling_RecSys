# G-SID — 중심화 + 직교주입 (τ 없음 · κ 0 · β₀ 0.5)

Split A · 코드북 폭 256 · 4층 · TIGER `clip_L4` 레시피 · 시드 42 기준.
탐색한 12조건 중 아래 규칙으로 고른 결과물입니다.

## 수식

```
zᵢ = x̃ᵢ + β₀‖x̃ᵢ‖ · unit( mᵢ − ⟨mᵢ, x̂ᵢ⟩ x̂ᵢ )        x̃ᵢ = xᵢ − μ,  β₀ = 0.5
mᵢ = Σ_{j∈N(i)} wᵢⱼ x̃ⱼ / Σ wᵢⱼ                       (간선 전부 · 나혜님 가중치)
```

1. **중심화** — 전체 평균을 뺍니다. 1층 k-means 가 L2 정규화로 방향만 보기 때문에
   중심화를 해야 그래프 신호가 배정에 반영됩니다.
2. **이웃 가중평균** — 관계 간선 482,523개를 전부 씁니다. 보완간선 필터(τ)는 쓰지 않습니다.
3. **직교주입** — 이웃 평균에서 자기 방향 성분을 뺀 나머지만 더합니다.
   자기 정체성을 덮어쓰지 않고 새 정보만 넣는 구조입니다.

### β₀ 의 의미

주입되는 항이 `β₀‖x̃ᵢ‖ × (자기 방향에 수직인 단위벡터)` 이므로 **회전각 = arctan(β₀)** 이고,
아이템의 노름·이웃 수·인기와 무관하게 **모든 아이템에 같은 각도**가 적용됩니다.

| β₀ | 길이비 (자기:이웃) | 회전각 | 에너지비 | 방향 최근접이웃 상위10 재배치 |
|---|---|---|---|---|
| 0.3 | 1 : 0.3 | 16.70° | 91.7 : 8.3 | 38% |
| **0.5** | **1 : 0.5** | **26.57°** | **80.0 : 20.0** | **60%** |
| 1.0 | 1 : 1.0 | 45.00° | 50.0 : 50.0 | 80% |

실측 확인: 12,101개 중 11,959개(98.8%)가 정확히 26.5651° 회전.
나머지 142개는 그래프 이웃이 0개인 아이템으로 원본을 그대로 둡니다.

⚠️ 이웃 기여분도 **이웃들의 텍스트 임베딩**에서 옵니다. 그래프는 누가 이웃인지와
가중치만 정합니다 — "텍스트 대신 그래프 정보를 넣었다"가 아닙니다.

**② 시드 1개입니다.** 시드 7 학습·덤프는 별도 진행 중입니다.

**③ 충돌률이 baseline 보다 높습니다** (10.31% → 12.45%). 숨기지 않고 적습니다.

**④ 충돌률이 낮은 게 좋은 것이 아닙니다.** 충돌 최저였던 조건


12조건 중 2조건이 APLT 제약에서 탈락하고, 통과한 10조건 중 COLD@50 최대가 이 조건입니다.
15개 지표 중 9개 1위 · 평균 순위 1.7 입니다.

## 아직 안 닫힌 축

`β₀` 가 회전각이라는 게 확인됐고, τ0.3 계열에서 β₀ 0.3 → 0.5 → 1.0 일 때
APLT 가 0.0730 → 0.0967 → 0.1058 로 **단조 증가**했습니다.
τ 를 뺀 계열은 β₀ 0.5 만 측정했으므로 **τ없음 × β₀ 1.0 (45°)** 이 다음 후보입니다.

블렌딩 계열도 α 0.3 → 0.5 → 0.7 에서 R@50 이 0.1653 → 0.1740 → 0.1754 로
단조 증가라 α 축이 안 닫혔습니다 (α 0.7 은 15지표 중 4개 1위 · 평균 순위 2.5).
